# CCNA Labs

Hands-on Cisco Packet Tracer labs covering core CCNA topics, built to demonstrate practical network configuration, troubleshooting, and verification.

## Labs

| # | Lab | Key Topics |
|---|-----|-----------|
| 04 | [OSPF Single Area](./04-ospf-single-area/) | OSPFv2 (Process 1, Area 0), dynamic routing, neighbor adjacency, multi-site connectivity |
| 05 | [Secure Corporate Network](./05-secure-corporate-network/) | VLANs, Router-on-a-Stick (802.1Q trunk), inter-VLAN routing, extended ACL, port security |

## Tools

- Cisco Packet Tracer
- Cisco IOS (CLI verification with `show` commands)

## How to Open a Lab

Download the `.pkt` file from the lab folder and open it in Cisco Packet Tracer. Each lab's README lists the verification commands and their expected output.

## Certification

CCNA (Cisco Certified Network Associate), completed via Coursera / Cisco.
